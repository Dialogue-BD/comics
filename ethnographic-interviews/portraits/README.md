# Speaker portraits

    portraits/<scenario-id>-<n>.jpg    n = 1, 2, 3 in the order the speakers appear

**All eighteen are in place.** 384x384 JPEG, about 26 kB each, half a megabyte
for the set. If a file is missing the page falls back to a tinted initial in the
brand's moss, so the activity still looks finished without them.

The prompts that produced these are in `../ethnographic-interviews-voice-script.md`,
one inside each speaker's section, each naming that speaker's ethnicity, dress
and the exact room the interview happens in. The full-size originals — 1254x1254
PNG, about 2 MB each — are kept in `_originals/`. The page never loads them; they
are there so a crop can be redone without going back to ChatGPT.

**If you regenerate one**, drop the full-size image in and crop it the way the
others were cropped rather than scaling the whole frame down. These are
environmental portraits — a nurse by a vending machine, an intern in a cafe —
and the subject is rarely centred, so a plain resize leaves a face a few pixels
wide. The recipe: find the face, take a square 2.1 times the face's width around
it, nudge the centre down 6% so the crop keeps shoulders rather than ceiling,
resize to 384 and save at JPEG quality 84.

Note the Brand Book's photography rule applies to Dialogue's own photography,
not to these: real sessions only, no filters or stock. These portraits are
openly synthetic informants inside a classroom activity, so keep them plainly
illustrative and never present them as photographs of real participants.
