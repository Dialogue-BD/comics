① 16 Core Vibecoding & Git Words

  • Vibecoding (VIBE-co-ding): Build apps by telling AI what you want in plain language.
  • API Key: Secret digital PIN connecting your app to AI — keep private!
  • Repository (re-POS-i-to-ry / Repo): Master vault. Commit: Working save point.
  • Push: Upload to GitHub. Pull: Download updates.
  • main: Official live track. HEAD: Where you are now.
  • Branch: Safe test track. Merge: Join branch into main.
  • Conflict: Two edits clash. Revert: Rewind safely.
  • Clone: Copy repo to IDE. Fork: Personal repo copy.
  • Diff: Red/green line check. Pull Request (PR): Safe merge review.

② Google AI Studio Flow

  1. Test live preview → click Save to GitHub → Private repo.
  2. Save a checkpoint after every working prompt.

③ AI IDE Visual Git

  1. Source Control (🔀) → Diff → ✓ Commit → ☁️ Sync Changes.
  2. Before risky redesigns: click 🔀 main → new branch.

④ 5 Golden Rules

  1. Test before Commit.
  2. Commit small & often (1 feature = 1 commit).
  3. Use clear English commit labels.
  4. Open a Branch before risky AI redesigns.
  5. Store keys in .env + .gitignore (revoke leaked keys!).

⑤ Client English

  • “Here is the live preview link on GitHub Pages.”
  • “I created a safe branch so your live app stays untouched.”
  • “I reverted to our previous working commit with zero downtime.”

⑥ Free Setup (No Dollar Card)

  1. Create free github.com account + sign into AI Studio / IDE.
  2. Publish via Settings → Pages → Branch: main.
