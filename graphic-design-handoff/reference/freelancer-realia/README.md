# Freelancer Realia Repository

Real freelancer–client conversations and first-person voices from Bangladeshi digital freelancers, collected for classroom use in Dialogue's PSDP curriculum design. These are the raw materials: the actual words, chat screenshots, proposals, and rate arguments freelancers post in their own communities.

## How it's organized

Each file is one conversation type — the moments where freelancing lives or dies:

- `01-first-contact-and-proposals.md` — proposals, cover letters, first messages to clients
- `02-pricing-and-negotiation.md` — quoting rates, haggling, raising prices, saying no
- `03-expectations-and-scope.md` — reporting demands, scope creep, "why no sales?" pressure
- `04-chasing-payment.md` — withdrawal pain, fee surprises, pricing backwards from taka
- `05-bad-news-and-conflict.md` — delivering bad news, disputes, bad reviews
- `06-ai-displacement-chats.md` — clients leaving for AI, in their own chat screenshots
- `07-platform-and-appeals.md` — bans, suspensions, appeal letters, going off-platform

## Entry format

Every entry keeps the quote **brief** (a line or two — fair-use excerpts, never full posts), plus context, source, and a classroom-use note:

```markdown
### Short title
**Voice:** who said it (first name/handle as publicly posted), where, date
**Link:** source URL when available
**The words:**
> brief quote
**Context:** one or two lines of paraphrase
**Classroom use:** one-line teaching idea
```

## Ground rules

- **Brief quotes only.** Never reproduce a full post, article, or long thread. One or two lines per entry.
- **Public posts only.** Everything here was posted publicly by the author in a public group, page, or forum.
- **Anonymized lightly.** First names/handles as posted; no phone numbers, emails, NIDs, or private details — ever.
- **Dated.** Every entry carries the date it was posted (or "circa" when the exact date isn't visible).

## How it grows

- **Nightly:** the daily freelancer-nugget research files the 2–3 best new client-conversation excerpts it finds.
- **On demand:** paste Tim a Facebook post/group link (or tell Sopher the group name and topic) and he'll pull the thread and file the best bits.
- **Direct group pulls:** reading Facebook groups directly needs the Facebook connection, which isn't linked right now. If Tim ever connects it, Sopher can browse groups like "Payoneer Bangladesh" or "The Freelancers of BD" and file threads straight from the source.
