# Spec Sheet: English for Freelancers — Graphic Design

## Module Identity

- **Title:** English for Freelancers — Graphic Design
- **Type:** Interactive classroom activity (dialogue-bd.com style — QR join, projection-optimized)
- **Audience:** PSDP students / English club / freelancing-track learners
- **Pedagogy:** Comprehensible input — every English term taught through a visual example first, label second. Students SEE the meaning before reading the word.
- **Design rule:** Integration over isolation — every section touches English + freelancing + tech tools + AI literacy+ design durable skills simultaneously, never as separate units.

## Sections

### 1. Typography

- **Concepts:** serif vs sans-serif, font pairing, readability, hierarchy through type
- **Comprehensible input:** side-by-side visual comparisons — students see the difference, then learn the English label
- **Freelancing angle:** "The client said 'make it pop' — what do they actually mean?" Translating vague client feedback into design decisions
- **Vocabulary:** serif, sans-serif, typeface, font, hierarchy, kerning, leading, legibility

### 2. Color

- **Concepts:** color theory basics, contrast, palette building, mood/psychology
- **Comprehensible input:** interactive swatches — click to see contrast ratios, good vs bad combinations
- **Freelancing angle:** brand color discussions with clients; "What colors represent your business?"
- **Vocabulary:** contrast, palette, saturation, hue, complementary, muted, vibrant

### 3. Layout & Composition

- **Concepts:** visual hierarchy, whitespace, alignment, grid, balance
- **Comprehensible input:** before/after sliders — drag to see bad layout become good layout
- **Freelancing angle:** presenting layout options to clients; justifying design choices in professional English
- **Vocabulary:** hierarchy, whitespace, alignment, grid, balance, focal point, clutter

### 4. Client Communication English (uses freelancer-client realia — CONFIRMED by Tim)

- **Concepts:** the language of design feedback — giving and receiving critique professionally
- **Format:** phrase bank with scenarios built from REAL freelancer-client conversations (from the realia repository: `~/workspace/goals/daily-freelancer-insight-nugget/files/freelancer-realia/`) — "The client says X, you respond Y"
- **Covers:** asking clarifying questions, pushing back politely, presenting options, handling "make it pop" / "I'll know it when I see it"
- **Vocabulary:** revision, draft, mockup, iteration, brief, feedback, deliverable

### 5. GenAI Media Creation Toolkit (cheapest, easiest, best — per Tim)

- **Scope:** the full media stack a freelance designer can generate with AI — not just images. Cover picture, music, TTS/voiceover, sound effects, video, motion graphics, animation, typography, and Canva's AI features.
- **Format for each category:** cheapest option → easiest option → best option, with free-tier availability in Bangladesh as the deciding factor. What it does, when a designer would use it, what it costs (or doesn't).
- **Freelancing angle:** this is the modern designer's toolkit — a solo freelancer can now produce what used to need a team. But knowing which tool for which job (and when NOT to use AI) is the skill.
- **Vocabulary:** prompt, iteration, seed, aspect ratio, style reference, upscaling, voiceover, sound design, keyframes, rendering

### 6. Visual Communication — The Pixar Lens (per Tim)

- **Concepts:** lighting, color, perspective, SHAPE LANGUAGE — and how they communicate. From Pixar in a Box: every visual choice tells the viewer something. That IS design.
- **Shape language:** circles read as friendly/safe, squares as stable/strong, triangles as dynamic/dangerous. Pixar uses this for character design — students learn to see it in logos and branding too.
- **Culture shapes design:** color and symbol choices carry different meanings across cultures (white = purity in the West, mourning in parts of Asia; red = luck in China, danger in the West). A freelancer working with global clients MUST know this — it's a professional survival skill, not trivia.
- **Reading direction shapes layout:** LTR cultures (English, Bangla) scan left-to-right; RTL cultures (Arabic, Hebrew, Urdu) scan right-to-left. Eye-tracking patterns mirror. A layout that "flows" in English feels backwards in Arabic — logos, navigation, progress indicators, and visual hierarchy all flip. A freelancer designing for a Gulf client needs to know this cold.
- **Comprehensible input:** same scene rendered with different lighting/color/perspective — students see how the meaning changes, then learn the English to describe it. Same logo concept in different shapes — feel how the personality shifts.
- **Tim's insight:** Bangladesh is a high-context culture — a lot goes unsaid, meaning lives in what's shown not told. That visual literacy is a design instinct. The module names it and builds on it: "You already read images. Now learn to make them."
- **Freelancing angle:** this is art direction — the skill clients pay for that AI can't replicate. When you can explain WHY a visual choice works, you're not a button-pusher, you're a consultant. Cross-cultural design awareness is a premium differentiator.
- **Vocabulary:** lighting, shadow, perspective, focal point, mood, tone, composition, visual storytelling, shape language, cultural context

### 7. AI Generation ≠ Design

- **Concepts:** the human judgment layer — why generating an image is not designing
- **Covers:** taste, hierarchy decisions, client understanding, knowing when output is wrong, iteration with intent
- **Format:** "spot the problem" exercises — AI-generated designs with subtle flaws students must identify and fix
- **Durable skill framing:** AI is the tool, design is the thinking. The designer who can direct AI beats both the pure AI user and the designer who ignores AI.
- **Connects to:** the Pixar lens (section 6) — the judgment to know good lighting/color/perspective/shape-language from bad IS the design skill
- **Vocabulary:** curation, art direction, intent, refinement
