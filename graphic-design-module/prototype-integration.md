# Prototype teaching patterns adopted

| Prototype strength | Integration in this module |
|---|---|
| A picture teaches the term before a definition | Motion examples first; visual vocabulary picture cards; definitions and feature notes open on tap. |
| A small set of clear choices | Three starter cards per medium; the full independent range remains available. |
| Visible cause and effect | Named lab choices change graphics and prose before the explanation is revealed. |
| Short, concrete instructions | Forty-five action prompts edited for ESL access, with spoken noticing questions and meanings. |
| Movement matching | Existing sentence/line matching retained with immediate partner feedback. |
| Word painting | Existing palette/word/speech agreement, subtle mood colours, and kinetic word art retained. |
| Recognisable page silhouettes | Existing document-template matching and ten forms, including concrete poetry and Oulipo, retained. |
| Sound sorting and resonance | Existing rough/smooth sorting, sound effects, music theme, and listening controls retained. |
| Structural depth beneath a page | Restored five-step chiasm; story arc, frame, flashback, strands, and turning-point examples retained. |
| Space for the unsaid | Paragraph/line/scene gaps, ellipses, dashes, and several evidence-supported subtext readings retained. |
| A crooked grammatical shelf | A chosen verb form visibly changes the paper alignment in the repair challenge. |
| A punctuation fulcrum | Existing prominent colon beam and explanatory-clause building retained; punctuation jobs stay distinct. |
| Paragraph magnets and ordered stacks | Existing grouping, drag controls, keyboard alternatives, and reading-order challenges retained. |
| Refrains and verbal bookends | Existing echo/repetition examples and fresh-case closing challenge retained. |
| Word surgery | Cuttable fragments read as one sentence; word count and edited meaning update immediately. |
| Purpose determines the form | Existing cause/explanation, narrative, and practical-detail challenges retained. |
| Surface → depth → omission | Linked mini-guide across Shape, Form, and Space. |
| Begin in the chosen medium | Written or visual entry determines example order. |

The two-dimensional/three-dimensional design distinction, actual language examples, optional authentic readings, source attribution, original word animations, paper materials, bottom coach, saved progress, and open navigation are preserved. Current curriculum decisions remain: no progression gates or mandatory prose rewriting; colour and shape associations depend on context; punctuation explains relationships rather than matching clause lengths. The integrated module remains fifteen paired units and a finale.
